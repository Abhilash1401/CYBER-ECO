# Security Policy

## Supported Versions

Only the latest release of Cyber Eco receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

As a Bug Bounty platform, we take the security of Cyber Eco with the utmost seriousness. If you discover a vulnerability within this codebase or any hosted instance, please disclose it responsibly.

### How to Report:
- **Email**: Send detailed vulnerability reports to `security@cybereco.local` (or your designated platform security email).
- Include:
  - Description of the issue and potential impact
  - Step-by-step reproduction guide or proof-of-concept (PoC)
  - Affected components, endpoints, or commit hashes
  - Suggested remediation if available

### Response Commitments:
- **Initial Response**: Within 24-48 business hours.
- **Triage & Assessment**: Within 5 business days.
- **Fix & Advisory**: We coordinate patches in private before publishing advisories.

Please do **NOT** submit public GitHub issues for security vulnerabilities.
